The R script "fix_ghgscout_data.R" should be used to process raw data from the Picarro gas analyzer. All .dat files from Picarro are stored in the "ghg" folder. Running the script generates plots of CO₂ and CH₄ concentrations (ppm) over time for each measurement. The linear section of each plot should be selected (by clicking), which creates a corresponding CSV file containing the defined interval data, which will be saved separately for each gas (CO₂, CH₄) in the ghg folder. The R script fluxes_ghgscout_data.R calculates CO₂ and CH₄ fluxes using the CSV files generated in the previous step with "fix_ghgscout_data.R" (stored in the "ghg" folder). These files are used to estimate the slope of the linear relationship between gas concentration (ppm) and time. The script also uses "metadata.csv" in the "data" folder, which contains information on temperature, chamber volume, pressure, start time, and the corresponding file code for each .dat file.
